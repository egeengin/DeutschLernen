# Ресурси та корисні посилання (telc B1)

## Офіційні джерела

- **Офіційні практичні тести telc:** [telc.net/practice-exams](https://www.telc.net/sprachpruefungen/deutsch/zertifikat-deutsch-telc-deutsch-b1.html)
- **Програма та регламент B1 (Übungstest):** Детальні критерії оцінювання від telc — див. сторінки 39–42 офіційного PDF-файлу.

## Відеокурси

- **Learn German with Anja:** Чудові пояснення тем граматики B1.
- **YourGermanTeacher:** Відмінні відео зі стратегіями складання іспиту.
- **DW Learn German:** Курс "Nicos Weg" для рівня B1.

## Цифрове навчання

- **DW — Nicos Weg (B1):** Інтерактивний відеокурс від Deutsche Welle.
- **Lingolia:** Комплексні граматичні пояснення та таблиці німецької мови.
- **Duden:** Стандартний словник німецької мови для правопису та слововживання.

## Рекомендовані додатки

- **Anki / Quizlet:** Для запам'ятовування лексики інтервальним методом.
- **Додаток Deutsche Welle:** Для щоденної практики аудіювання.
- **Babbel / Duolingo:** Для регулярної підтримки базового словникового запасу.
- **HelloTalk / Tandem:** Додатки мовного обміну для практики розмовної мови з носіями.
