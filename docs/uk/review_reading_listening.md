# Комплексний огляд: Читання та аудіювання (Lesen & Hören)

______________________________________________________________________

## 1. Розділ "Читання" (Lesen) — 45 хвилин

### Головні стратегії для максимального балу

1. **Спочатку читайте запитання**, а вже потім шукайте ключові слова в тексті. Ніколи не читайте довгі тексти повністю перед ознайомленням із завданням.
2. У розділі зіставлення оголошень: викреслюйте використані варіанти, щоб звузити вибір.
3. Не панікуйте через незнайомі слова; зосередьтеся на **загальному контексті**.
4. Тайм-менеджмент: виділяйте **максимум 90 секунд** на твердження "правильно/неправильно" та **до 2 хвилин** на завдання з вибором відповіді.

### Ключова навичка: Розпізнавання синонімів (Synonym Recognition)

У тестах telc запитання майже завжди перефразовують текст іншими словами:

| У тексті написано... | У запитанні / варіанті відповіді... |
| --- | --- |
| **kostenlos / gratis** (безкоштовно) | ohne Bezahlung / kostet nichts (без оплати) |
| **Kinder** (діти) | Nachwuchs / die Kleinen (малеча) |
| **Arzt / Krankenhaus** (лікар/лікарня) | medizinische Hilfe (медична допомога) |
| **kaufen / einkaufen** (купувати) | erwerben / besorgen (придбати) |
| **Rabatt / billiger** (знижка / дешевше) | Ermäßigung / Reduzierung (зниження ціни) |
| **Wohnung** (квартира) | Unterkunft (житло) |
| **anrufen** (телефонувати) | telefonieren / sich melden (зв'язатися) |
| **Arbeit** (робота) | Beruf / Stelle / Job (професія / посада) |
| **Wochenende** (вихідні) | Samstag und Sonntag (субота й неділя) |
| **täglich** (щодня) | jeden Tag / von Mo bis So (кожен день) |

### Підступні фрази в тестах
- **nicht alle:** деякі, але не всі (це НЕ означає: ніхто).
- **kaum / fast nie:** майже ніколи (НЕ означає: зовсім ніколи).
- **nur manchmal:** лише іноді (НЕ означає: часто).
- **immer noch nicht:** усе ще ні.
- **erst:** лише тоді / не раніше ніж.

## 3. Розділ "Аудіювання" (Hörverstehen) — близько 30 хвилин

### Головні поради для аудіювання

1. **Використовуйте час читання завдань:** Коли диктор зачитує загальні правила, не слухайте їх! Використовуйте ці секунди, щоб швидко прочитати запитання та підкреслити ключові слова.
2. **Остерігайтеся пасток і відволікань (Distractors):** Часто в записі озвучуються всі три варіанти (A, B, C)! Слухайте саме фінальний зміст і висновок, а не просто знайоме слово.

### Приклад відволікання в аудіюванні

**У завданні:** Wann kommt Frau Müller? (Коли прийде пані Мюллер?)  
A) 10 Uhr | B) 12 Uhr | C) 14 Uhr  

**В аудіозаписі:** *"Guten Tag Herr Schmidt, hier ist Müller. Unser Termin war ja eigentlich für 12 Uhr geplant. Leider habe ich den Bus um 10 Uhr verpasst. Können wir uns stattdessen um 14 Uhr treffen?"*
