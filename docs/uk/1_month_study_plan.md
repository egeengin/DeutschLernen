# 1-Місячний інтенсивний план підготовки до B1 (Українською)

## Огляд

Цей розклад розрахований на 2-3 години занять щодня, 6 днів на тиждень, із цільовою орієнтацією на успішне складання іспиту **telc Deutsch B1**.

---

### Тиждень 1: Граматична база та мовні структури

**Мета:** Опанувати частину "Sprachbausteine" (граматичні структури), яка є ключовою для читання та письма.

| День | Тема | Завдання |
| :--- | :--- | :--- |
| **День 1** | Діагностика | Пройти вхідний пробний іспит, виявити слабкі місця. |
| **День 2** | Сполучники | Сполучники нульової позиції (ADUSO: aber, denn, und, sondern, oder) проти сполучників з інверсією (deshalb, trotzdem). |
| **День 3** | Підрядні речення (Nebensätze) | Сполучники підрядності (weil, dass, wenn, ob, obwohl). **Дієслово завжди йде в кінець.** |
| **День 4** | Минулі часи | Perfekt (haben проти sein) та модальні дієслова в Präteritum. |
| **День 5** | Прийменники з подвійним керуванням | Wechselpräpositionen: коли вживається Dativ (місцезнаходження), а коли Akkusativ (напрямок руху). |
| **День 6** | Прикметники | Відмінювання прикметників (Adjektivdeklination) та ступені порівняння. |
| **День 7** | Закріплення | Практика відмінювання прикметників та основи пасивного стану (Passiv). |

---

### Тиждень 2: Читання та аудіювання

**Мета:** Розвинути швидкість читання та навчитися шукати синоніми (ключові слова).

| День | Тема | Завдання |
| :--- | :--- | :--- |
| **День 8** | Читання 1 і 2 | Підбір заголовків (Teil 1) та детальне читання з вибором a/b/c (Teil 2). |
| **День 9** | Читання 3 | Зіставлення оголошень із ситуаціями. **Увага на ситуації без оголошень (позначка "x").** |
| **День 10** | Аудіювання 1 | Короткі монологи — правильно/неправильно. Звучить **лише 1 раз**! |
| **День 11** | Аудіювання 2 | Довге інтерв'ю — 10 запитань. Звучить двічі. |
| **День 12** | Аудіювання 3 | Короткі публічні оголошення — правильно/неправильно. |
| **День 13** | Лексичний спринт | Тематичний словник: "Здоров'я та медицина", "Установи, відомства та формуляри". |
| **День 14** | Проміжний огляд | Половинний пробний тест: тільки аудіювання та читання. |

---

### Тиждень 3: Стратегії письма та усного мовлення

**Мета:** Вивчити шаблони листів та розмовні кліше (Redemittel).

| День | Тема | Завдання |
| :--- | :--- | :--- |
| **День 15** | Структура листа | Офіційний email: звертання (Anrede), відповідь на 4 пункти (Leitpunkte), прощання. |
| **День 16** | Шаблони листів | Резюме/заява на роботу (Bewerbung), відповідь на запрошення, лист-скарга (Beschwerde). |
| **День 17** | Тренування письма | Написання повного листа з таймером (30 хвилин). |
| **День 18** | Усна частина 1 | Відпрацювання самопрезентації (вік, країна, професія, сім'я). |
| **День 19** | Усна частина 2 | Висловлювання на тему: переказ думки та аргументація власної позиції. |
| **День 20** | Усна частина 3 | Спільне планування: внесення пропозицій, згода та ввічлива відмова. |
| **День 21** | Лексичний спринт | Тематичний словник: "Робота та кар'єра", "Житло та пошук квартири". |

---

### Тиждень 4: Повна симуляція та фінальний іспит

**Мета:** Напрацювати витривалість та усунути дрібні помилки.

| День | Активність | Завдання |
| :--- | :--- | :--- |
| **День 22** | Повна симуляція | Проходження повного письмового іспиту без перерв (150 хв). |
| **День 23** | Аналіз помилок | Детальний розбір помилок у складних сполучниках. |
| **День 24** | Симуляція розмови | Запис свого голосу під час виконання всіх 3 усних завдань, оцінка зв'язності. |
| **День 25** | Швидкісне письмо | Написання 2 різних листів по 30 хв кожен. |
| **День 26** | Фінальний пробний іспит | Виконання фінального тесту з ціллю ≥60% у кожній секції. |
| **День 27** | Шліфування | Повторення розділу "Типові помилки" у модулі граматики. |
| **День 28** | Повторення лексики | Марафон карток: усі базові дієслова та іменники A1–B1. |
| **День 29** | Відпочинок | Легкий перегляд мовних кліше. Підготовка документів до іспиту. |
| **День 30** | **ДЕНЬ ІСПИТУ** | Будьте спокійні та впевнені — ви чудово підготувалися! |
